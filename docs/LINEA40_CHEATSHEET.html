LiNEA40 Keymap Cheatsheet

Source: config/LiNEA40.keymap / left-side encoder + right trackball / 40-key build

QWERTY 30キー維持 Left encoder (pos 32 = none) IME = LC / RC(Space) Scroll layer = 4
Layer 2 左親指 Space または右 Ctrl+Space ホールドで記号・数字。左側数字は1-5／6-0の2段。
Enter / Layer 3 右親指 Enter はタップで Enter、ホールドで Fキー・ナビ。エンコーダー2ノッチでWindowsのウィンドウ切り替え。
IME 左最内側は LC Space／hold LShift、右最内側は RC Space／hold Layer 2。
Trackball Scroll ; をホールド中、トラックボール移動を Layer 4 スクロールへ変換。
通常キー tap/hold または layer マウス操作 combo（2キー間のラベルが動作） 物理キーなし / encoder

Encoder / ZMK Studio

Encoder 通常はホイールスクロール。Layer 2 では2ノッチごとにChromeの前後タブ、Layer 3 では2ノッチごとにWindowsの前後ウィンドウ、Layer 4 では上下キー。
ZMK Studio Enter をホールドしてLayer 3に入り、右 Ctrl を押すとStudio編集を解除。

Combos

同時押し。RC Space + Enter はBaseレイヤーで有効。

H + JBack / MB4。
J + KLeft click。
K + LRight click。
, + .Forward / MB5。
RC Space + EnterCtrl + Enter。

確認ポイント: IME が期待と逆の場合は RC(SPACE) を LC(SPACE) / LANG1 / LANG2 に差し替える。
